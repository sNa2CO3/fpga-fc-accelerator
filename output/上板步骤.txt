Lab8 上板步骤
=====================================================

本目录需要的文件（全部 5 个）:
  lab8.bit            比特流（Vivado 生成）
  lab8.hwh            硬件描述（必须和 .bit 同一次生成）
  sel_data.coe        42 个样本输入
  sel_labels.txt      42 个标签
  lab8_npu.py         PS 端 Python 脚本

-----------------------------------------------------
方式 A：网线 + 浏览器（推荐）
-----------------------------------------------------
1. SD 卡插回 PYNQ-Z2，网线接到电脑，上电。
2. 电脑网卡设成 192.168.2.1/24。
3. 浏览器打开  http://192.168.2.99   （用户名/密码都是 xilinx）
4. 新建一个文件夹 lab8，把这 5 个文件上传进去。
5. 打开 Jupyter 的 Terminal（New -> Terminal），执行：
       cd lab8
       python3 lab8_npu.py        # 不要加 sudo!
6. 看输出：42 个样本、准确率 88.10%、时间。
   最后的特征图必须是：
       fc1[0:8] = [4, 1, 0, 0, 0, 0, 0, 0]
       fc2[0:8] = [3, 0, 3, 0, 0, 2, 5, 0]
       fc3      = [10, -11]

-----------------------------------------------------
方式 B：直接把文件放进 SD 卡
-----------------------------------------------------
把本目录的 5 个文件拷到 SD 卡的 FAT32 分区（盘符 G:，卷标 PYNQ）。
板子启动后这些文件在 /boot/ 下。
然后 SSH 进去（ssh xilinx@192.168.2.99，密码 xilinx）：
       cd /boot
       python3 lab8_npu.py        # 不要加 sudo!

-----------------------------------------------------
常见问题
-----------------------------------------------------
* ModuleNotFoundError: No module named 'pynq'
    → 用了 sudo。去掉 sudo 直接 python3 lab8_npu.py。
* 报 "no such IP"：.bit 和 .hwh 不是同一次生成，重新导出。
* 42 个结果全 0 或全乱：字节序问题，检查 PS 打包是否 MSB 优先。
* 只跑第一个样本就卡住：DMA 收不满，检查 tlast。
* 时间比 13.44us 大很多：正常，Python 端有打包和驱动开销，
  汇报时说明"PL 内部 13.44us，端到端 xx us"。

## 三种读法

**第一次接触这个项目** —— 按顺序读 00 → 01 → 02，大约 30 分钟能建立完整印象。

**准备答辩** —— 07 是主入口，遇到具体问题再回查：
- 架构/数据流 → 01
- 截位、准确率 → 03
- 时钟与资源数字 → 05
- 上板细节、时间口径 → 06、08

**想复现** —— 06 是操作手册，`scripts/` 里有完整的建工程、建 BD、出比特流、命令行仿真脚本；
08 记录了这台机器上 Vivado 2022.1 的五个固定坑（不按它来会白跑很多次）。

## 约定

- **文档里的数字都是实测值**，不是估算；估算值会明确标注（例如片上功耗来自 Vivado
  `report_power`，属工具估算）。
- **时间有两种口径**，写的时候必须说清楚：
  - **三层计算** 1144 拍 = 9.152 µs @125 MHz（纯运算）；
  - **整包** 1339 拍 = 10.712 µs（再加命令、收样本与输出）。
- 跨篇引用写作"见 05 篇 §6"这种形式，不写页码。
